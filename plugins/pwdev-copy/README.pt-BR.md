# PWDEV Copy — Framework de Copywriting Treinável

Este plugin já possui documentação principal em português em [README.md](./README.md).

Instalação:

```text
/plugin marketplace add pwdev-solucoes/pwdev-claude-marketplace
/plugin install pwdev-copy
```

Primeiro uso: execute `/pwdev-copy:treinar`, depois siga `voc`, `brief`, `copy`, `revisar` e `status`.
Consulte o README principal para comandos, skills, subagentes, regras de segurança e MCPs.
