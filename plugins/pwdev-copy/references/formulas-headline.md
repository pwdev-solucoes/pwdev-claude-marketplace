## Fórmulas de headline por ângulo

### Ângulo: resultado
- `{resultado desejado} sem {dor}` → "Feche o mês sem virar a noite na planilha"
- `{resultado} com {como o produto viabiliza}` → "Mais atendimentos com a mesma equipe"
- `Transforme {entrada} em {saída}` → "Transforme dado bruto em decisão de gestão"
- `{resultado} em {prazo}` → "Relatório pronto em 20 minutos"

### Ângulo: dor
- `Nunca mais {evento indesejado}` → "Nunca mais perca prazo de repasse"
- `{pergunta que nomeia a dor}` → "Cansado de consolidar planilha na mão?"
- `Pare de {dor}. Comece a {ganho}.`

### Ângulo: público
- `O {categoria} para {público}` → "O painel para secretarias de saúde"
- `{categoria} para {público} {finalidade}`
- `Você não precisa {habilidade} para {resultado}`

### Ângulo: diferenciação
- `O jeito {oposto do usual} de {resultado}`
- `O {categoria} que {diferencial}` → "O sistema que a equipe realmente usa"
- `Finalmente, {categoria} que {benefício}`

### Ângulo: prova
- `{número} {pessoas} usam {produto} para {resultado}`
- `{benefício principal, dito de forma seca}`

### Ângulo: novidade
Ogilvy: notícia é o gatilho mais barato de atenção — e o mais desperdiçado,
porque a maioria enterra o lançamento no corpo do texto.
- `Agora {produto} faz {novidade}`
- `Chegou {coisa} para {público}`

## Calibragem (Ogilvy)

| Elemento | O que vence |
|---|---|
| Comprimento de headline | 8-12 palavras para memorização; 6-12 para resposta |
| Conteúdo | marca + promessa + notícia |
| Comprimento de corpo | longo vence curto para quem já está interessado |
| Negativa | evitar em headline |
| Legenda de imagem | lida 2× mais que o corpo — escrever como anúncio autônomo |

## Estruturas de página

### Fraca — lista de funcionalidades
```
Hero → Func. 1 → Func. 2 → Func. 3 → CTA
```
É um inventário, não um argumento.

### Forte — narrativa com objeção
```
1. Hero com proposta de valor clara
2. Barra de prova social
3. Problema / dor
4. Como funciona (3 passos)
5. Benefícios (2-3, não 10)
6. Depoimento
7. Casos de uso ou personas
8. Comparação com a alternativa atual
9. Trecho de estudo de caso
10. FAQ
11. CTA final com reversão de risco
```

### Landing compacta (tráfego pago)
```
Hero → prova social → 3 benefícios → depoimento → como funciona → CTA com garantia
```

### B2B / enterprise
```
Hero orientado a resultado → logos → problema de negócio → solução →
casos por papel/área → segurança e conformidade → integrações →
caso com métrica → ROI → CTA de contato
```

### Setor público
```
Hero em linguagem cidadã → o que muda para a população →
como funciona (passo a passo) → transparência e dado aberto →
conformidade (LGPD, acessibilidade) → prova institucional →
canal de atendimento
```
Sem urgência artificial, sem escassez. A métrica é conclusão do serviço.

## Dicas por seção

**Problema** — abra com reconhecimento: "Se você é {papel}, conhece a cena:".
Descreva a frustração específica, o custo em tempo ou dinheiro, o impacto no trabalho.

**Benefícios** — cada um com título (o resultado), corpo (como, 1-2 frases) e
prova (número ou exemplo, quando existir).

**Como funciona** — numerado, verbo simples, orientado a resultado:
1. Conecte seus dados (2 minutos)
2. Escolha os indicadores
3. Receba o painel toda segunda

**Depoimento** — escolher os que trazem resultado específico e contexto
antes/depois, com nome e cargo. Descartar "ótimo produto", "adorei".
