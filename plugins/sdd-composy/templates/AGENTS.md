## Workflow

The canonical lifecycle is:

```text
INIT -> MAP -> PRD -> STORIES -> TECHSPEC -> TASKS
                                            |
                              EXECUTE -> QA -> EVIDENCE -> REVIEW -> VERIFY
                                       ^       autonomous LOOP       |
                                       +-----------------------------+
                                            |
                                         COMPLETE
```

`QUICK` is a reduced path limited to 5 implementation files. Escalate to the full
lifecycle before editing when work requires architecture, migrations, destructive
operations, scope expansion, or unknown verification. `LOOP` is bounded at 3
iterations by default. `FLEET` accepts only independent ready tasks in isolated
worktrees; cmux, tmux, or headless presentation never owns lifecycle truth.

## Gates

- PRD, applicable STORIES, TECHSPEC, TASKS execution scope, and completion require
  explicit human approval. Artifact existence or model confidence never implies approval.
- STORIES may be `NOT_APPLICABLE` only for pure internal work and must include an
  explicit justification.
- A task may become `ready` only when dependencies are complete, acceptance criteria
  and verification commands are known, and its contract is approved.
- Completion requires fresh test evidence, non-blocking QA and review, an independently
  approved verification verdict, and consistent traceability.
- Rejected gates return to the artifact that owns the decision; stale downstream
  artifacts must be reconciled before reuse.
- Fleet branches are never merged automatically. Merge requires explicit authorization.

## Artifacts

Human contracts live under `tasks/prd-<slug>/`; the bundle root is `tasks/index.md`.
The index uses `okf_version: "0.2"`, and every generated non-reserved Markdown document
has OKF frontmatter with a non-empty `type`, provenance, lifecycle metadata, sources,
and explicit verification events where applicable.

Operational artifacts live under `.planning/sdd-composy/`:

```text
config.json, state.json
context/{project,stack,domain,pitfalls}.md
context/codebase.json
tasks/index.json, tasks/<prd-slug>.json
trace/events.jsonl, trace/trace.json
loops/, fleet/, fleet-results/, fleet-logs/, reports/
```

Markdown owns intent, decisions, narrative acceptance contracts, and approvals.
Validated JSON owns current operational state; `trace/events.jsonl` is append-only;
`trace/trace.json` is a deterministic projection and is never edited directly.
Synchronizers report Markdown/JSON divergence before writing and never silently choose
an authority. Evidence paths are confined repository-relative regular files with
SHA-256 digests, known result/type values, and escaped or sanitized report text.

## Safety

- Never overwrite existing governance files, symlinks, `.agents`, or `.claude` paths.
  Initialization creates only missing files and diagnoses conflicts. Create `.claude ->
  .agents` only after compatibility and collision preflight.
- Never read .env, credentials, tokens, private keys, certificates, or existing fleet
  environment files. Do not display, migrate, reuse, adopt, or audit their contents.
- Never infer human approval from artifact existence, metadata, summaries, or confidence.
- Never change approved requirements, stories, architecture, acceptance criteria, or
  scope during autonomous execution.
- Always preserve unknown JSON fields. Validate before publication, write through a
  same-directory temporary file, and use atomic replacement.
- Append semantic events only after the represented action succeeds. Never repair
  malformed JSONL or edit `trace.json` directly to conceal disagreement.
- Stop for destructive work, external authorization, architectural ambiguity, scope
  expansion, missing progress, unrecoverable environment failure, or cancellation.
- Never merge fleet branches automatically; preserve recoverable branches and worktrees
  after failure.

When a conflict or unsafe condition is found, report the exact paths, evidence, and
next human action. Do not guess or mutate around the guard.
