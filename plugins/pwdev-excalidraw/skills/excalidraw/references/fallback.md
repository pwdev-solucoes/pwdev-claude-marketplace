# Fallback quando o MCP está indisponível

Nunca afirme que um diagrama remoto foi criado sem uma resposta bem-sucedida do MCP.

Ofereça uma alternativa compatível com o pedido:

- contrato visual em Markdown;
- diagrama Mermaid;
- fluxo ASCII;
- arquivo `.excalidraw` local, quando solicitado e seguro.

Informe claramente:

1. que o MCP não está disponível ou falhou;
2. qual fallback foi produzido;
3. o que ainda precisa ser feito quando o MCP voltar;
4. quais premissas permanecem sem validação.

Não invente uma URL, identificador, screenshot ou resultado de tool. Um fallback é uma saída útil, mas não é equivalente à criação remota no Excalidraw.
