# Roadmaps e dependências

Use esta referência para organizar entregas, marcos, dependências e ordem de execução.

## Estrutura mínima

- entregas ou marcos;
- dependências entre itens;
- bloqueios e riscos;
- itens sem data conhecida;
- legenda para confirmado, proposto e bloqueado.

Não invente datas, esforço ou precedência. Se a ordem não estiver definida, mostre a dependência como desconhecida em vez de criar uma sequência artificial.

## Verificação

Confirme que não há ciclos acidentais, que bloqueios estão visíveis e que cada dependência aponta para um item existente.
