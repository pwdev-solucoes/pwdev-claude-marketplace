# PWDEV Social Media — Produção de Criativos

Este plugin já possui documentação principal em português em [README.md](./README.md).

Instalação:

```text
/plugin marketplace add pwdev-solucoes/pwdev-claude-marketplace
/plugin install pwdev-social-media
```

Primeiro uso: execute `/pwdev-social-media:init` e depois `gerar` ou `criar`. Nunca coloque
chaves de API em arquivos do projeto; consulte o README principal para o pipeline e os gates de custo.
