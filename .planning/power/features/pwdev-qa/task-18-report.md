## Implemented contract

- `qa-test` preserves objective, contract, criteria, case selection, and authorization; records
  case/criterion IDs, expected and observed values, evidence, limitations, defects, and verdict.
- `qa-explore` produces a bounded charter, chronological notes, findings, and follow-up while
  refusing to treat exploration alone as evidence of `PASS`.
- Both workflows enforce explicit authorization for load, penetration, production, and external
  effects; do not install, publish, change personal configuration, or correct product code
  without a separate request.
- Shared skill bodies contain no Claude-only runtime tokens. Claude command wrappers only load
  the shared skill, forward arguments and repository context, and return its result unchanged.
